# -Syntecxhub_E-commerce_Product_Details_Page
Designed a product details page for Sneak Peek's AirFlow Pro sneakers. Features include image gallery with zoom, size/color variants, add-to-cart with micro-interaction, customer reviews, and a "More from Sneak Peek" section. Built in Figma using components and variants. Minimalist color palette: cream background, terracotta accents.
